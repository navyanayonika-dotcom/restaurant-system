# 🍽️ MYSTIC RESTAURANT

A simple Python-based restaurant management and billing system.

## 📌 About the Project

MYSTIC RESTAURANT is a beginner-friendly Python project that simulates a restaurant ordering system. Customers can view the menu, select items and quantities, and receive a final bill with GST.

## ✨ Features

- 👤 Takes the customer's name
- 📋 Displays the restaurant menu
- 🛒 Allows customers to order multiple items
- 🔢 Takes the quantity of each item
- 💰 Calculates the subtotal
- 🧾 Generates an itemized bill
- 🧮 Calculates 5% GST
- 📅 Displays the order date and time
- ✅ Displays the final amount and payment status
